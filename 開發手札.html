趨同決策

  • React 為慣例基準：Vue 端向 React 的六件套結構、BEM class、--cl-* token、a11y 語意靠攏。理由：React 版是後寫的，README 已記錄從 Vue 版學到的教訓（空值由父層負責、loading 不設 disabled）。
  • 共用元件清單 8 個：Button、SearchBar、StatusCard、StationCard、TabBar、AppHeader、EmptyState、Loading。地圖類、RoutePlanner、NewsFeedCard、Toast/Dialog 明列為本輪不做。
  • API 統一規則：「有 actionText 才顯示按鈕」取代 showAction 布林；arrivalTime 缺值顯示「更新中」文字而非 spinner（兩邊可測、一致）。
  • icon 不綁圖庫：TabBar / EmptyState 的 icon 收字串（emoji 或文字），避免 React 端被迫裝 iconify。
  • 規格檔位置：../COMPONENT-SPEC.md 放在兩 repo 的共同父目錄，任一邊改 API 先改規格。

踩坑記錄

  • 兩 repo 起始都沒 node_modules。React 端 npm install 一次過。
  • Vue 端安裝失敗兩次：先是 storybook@^7.5 與 @storybook/*@^8.6 peer 衝突；改版號後撞到 ~/.npm-cache 一筆損壞快取（EACCES rename / File exists，同一 sha512）。解法：npm install --cache <scratch dir> 換乾淨快取，不刪使用者快取。
